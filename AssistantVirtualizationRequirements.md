Virtual Environment Requirements:

* Assistant has been tested on the following hypervisors:
  * ESXi 8 and 9
  * Hyper-V
* Resources should be devoted to the Assistant VM and not shared.

Minimum Virtual Machine Requirements:
* Hard drive
  * 256 GB Volume C:\
  * 150 MB/s Sustained Transfer Rate
* RAM
  * 16 GB
* CPU
  * 8 cores 2.4GHz or higher
* Network
  * 1 Gigabit connection
  * static IP
